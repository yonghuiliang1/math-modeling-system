# 技能注册表模块

> **模块定位**：技能信息的唯一真实来源，所有阶段文件通过引用技能ID来调用技能。SKILL.md 中的技能调用矩阵改为"详见技能注册表.md"，不再手写维护。

> **与横切机制的边界**：横切机制.md 机制3（AI痕迹消隐）中的工具列表引用本模块。本模块是技能信息的唯一真实来源。

---

## 技能ID分配规则

- 格式：`SKILL_{三位数字}`
- 一经分配不可变，只改名称不改ID
- 新增技能追加到末尾，不复用已删除的ID

## 五、扩展指南

### 添加新技能

1. 分配新的技能ID（末尾追加，不复用已删除ID）
2. 填写技能注册信息表（名称、描述、适用阶段、调用角色、输入输出、替代技能、版本）
3. 在"技能调用矩阵"中添加该技能的行
4. 如有优先级关系，在"技能间优先级关系"中添加
5. 更新SKILL.md中的引用

### 替换技能

1. 找到要替换的技能ID
2. 修改技能名称（ID不变）
3. 更新输入输出规范
4. 检查"替代技能"字段和优先级关系
5. 检查下游步骤是否依赖原技能的特定输出格式
6. 全局搜索确认无残留旧名称引用

### 修改技能信息

1. 找到对应技能ID的注册信息表
2. 修改需要变更的字段
3. 同步更新"技能调用矩阵"和"技能间优先级关系"
4. 技能ID不可变，只改名称不改ID
